# backend — .NET 10

Modular monolith: one solution, several hosts. Rules: [`CLAUDE.md`](CLAUDE.md) · standards: [docs/engineering](../docs/engineering/README.md).

```
backend/
├── XDrishti.slnx · global.json · Directory.Build.props · Directory.Packages.props · .editorconfig · Dockerfile
├── contracts/XDrishti.Api.json       OpenAPI contract (generated by scripts/gen-api.sh)
├── src/
│   ├── XDrishti.Domain               entities & value objects (pure, no dependencies)
│   ├── XDrishti.Application          use cases (query/command handlers) + ports
│   ├── XDrishti.Infrastructure       EF Core / Npgsql, migrations, adapters
│   ├── XDrishti.Hosting              shared host defaults (secrets, Serilog, app info)
│   ├── XDrishti.Api                  HTTP host (endpoints, OpenAPI, health, `migrate`)
│   └── XDrishti.Worker               background host (heartbeat now; scheduled services later)
└── tests/                            Domain, Application, Architecture, Api.IntegrationTests
```

| Task | Command |
|------|---------|
| Build | `dotnet build XDrishti.slnx` |
| Test (all, incl. TimescaleDB in Podman) | `dotnet test --solution XDrishti.slnx` |
| New migration | `dotnet ef migrations add <Name> --project src/XDrishti.Infrastructure --startup-project src/XDrishti.Infrastructure --output-dir Persistence/Migrations` |
| Run API locally (hot reload) | `../scripts/dev-api.sh` → http://localhost:5080 |
