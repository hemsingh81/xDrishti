# scripts

Developer helpers.

| Script | What it does |
|--------|--------------|
| `build-docs.sh` | Rebuilds the HTML docs (`docs/site`) from `docs/design/*.md` |
| `serve.sh` | Serves the prototype (port 8766) and the docs site (port 8765) locally |

Later: `bootstrap.sh` (first-time setup), `dev.sh` (run backend + frontend), `test.sh`.
