# P1-10a — Corporate actions and price adjustments

- **Status:** Approved (owner, 2026-10-12) · decision [ADR 0017](../adr/0017-trading-calendar-eod-schedule-quality-adjustments-and-csv-undo.md) §5 · **Phase:** P1 — **P1-10** · depends on P1-17a (daily bars), P1-14a for the alert slot
## Backend
1. Table `market.corporate_actions (id, instrument_id, ex_date, kind split|bonus, numerator, denominator (e.g. split 1:5 = old 1 → new 5; bonus 1:1), factor (price multiplier for bars before ex_date, e.g. 0.2), status suggested|applied|ignored, source manual|detected|csv, note, created_at, decided_at, decided_by)` unique (instrument, ex_date, kind); grants (UPDATE ok, no DELETE — ignore instead).
2. **Detection** (pure, unit-tested, runs after aggregate phases and on request): from `bars_agg` 1D of each instrument find ex-date candidates where `open(d)/close(d−1)` (or close/close) is within 2.5 % of a common factor (1/2, 1/3, 1/4, 1/5, 1/10, 2/3, 3/4, 1/20 …) AND volume(d) ≥ 1.5 × the 20-day median, and the move is not reversed within 3 sessions; creates `suggested` actions with the matching ratio; never auto-applies; idempotent.
3. API: `GET /api/data/corporate-actions?status&instrumentId&page`, `POST` (manual add: instrument, exDate, kind, numerator, denominator, note → `applied`), `PUT /{id}` (edit ratio/date; confirm a suggestion → `applied`), `POST /{id}/ignore`, `POST /api/data/corporate-actions/detect` (run detection), CSV import `POST /api/data/corporate-actions/import` (text body or file: symbol, exDate, kind, numerator, denominator; preview counts, unknown symbols listed, never guessed, duplicates skipped). Audit events for decisions.
4. **Adjusted reads:** `GET /api/data/instruments/{id}/bars?...&adjusted=true` multiplies OHLC by the cumulative backward factor of all `applied` actions after the bar's date and divides volume by it (rounded sensibly, factor shown in the response: `adjustment {applied: n, factor}`); raw stays default. A reusable `IAdjustmentFactors` service for later research reads. Quality hook: pending `suggested` count in the quality overview and Data overview (`pendingCorporateActions`).
5. Tests: detection on fixtures (a 1:5 split, a 1:1 bonus, a false positive reversed in 2 days, a gap-down with no volume), factor math (two actions, order, boundary day, volume), CRUD/ignore/idempotency, CSV import cases, adjusted read, grants, contract, docs 05 §1/§9 and plan.
## Frontend
On the Data page a **Corporate actions** card/tab: list (instrument, ex-date, kind, ratio, factor, status chip, source) with filters; **Suggested** rows with Confirm / Edit / Ignore, **Add action** dialog, **Import CSV** dialog with preview; an alert strip on the Data page and slot on Data quality ("N suggested corporate actions to review"); the bars drawer gets an **Adjusted prices** switch showing the factor. Tests, a11y.
